The funniest possible voicemail greeting recorded by a cat — busy with its real work, and the caller can wait until after the meow.

## The line

> You've reached the cat. I'm busy knocking things off tables. Leave a message after the meow.

A proper voicemail frame (greeting, excuse, leave-a-message instruction) spoken by the cat itself, in the cat's own unbothered voice. The joke is cat-specific — knocking things off tables is the classic cat crime — and "after the meow" twists the expected "after the beep" as the final word.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (92 characters, UTF-8, deterministic — repeated runs produce byte-identical output). The line is well within the 120-character limit, a single line with no trailing newline.
